# Changelog

All notable user-visible changes to the Audiobookshelf TOS application package.

## 2.37.2-1 — 2026-11-14

### Added
- First release. Audiobookshelf (`moechz/audiobookshelf:2.37.2`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8159 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/audiobookshelfdocker/`.
