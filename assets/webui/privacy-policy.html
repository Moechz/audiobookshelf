Audiobookshelf Server — Privacy Policy

本文档为双语隐私政策。英文版在前，中文版在后。（This document is bilingual: English first, Chinese below.）

1. Overview

Audiobookshelf Server is a self-hosted audiobook and podcast server that runs entirely on your own NAS device (TerraMaster TOS 7). The package (published by Moechz) contains the official upstream Audiobookshelf build and does not add any analytics, telemetry, tracking, or advertising SDKs. It does not collect, transmit, or share any personal data with the publisher.

2. Data stored on your device

DataLocationPurpose
Account names and password hashes/var/lib/audiobookshelf/config/ (SQLite)Login to the web UI
Library database (books, progress, bookmarks, notes)/var/lib/audiobookshelf/config/absdatabase.sqliteCore application state
Cover art, cached metadata, downloaded podcasts/var/lib/audiobookshelf/metadata/Media processing and offline reading
Backups/var/lib/audiobookshelf/config/backups/Manual/automatic backups
Server configuration/usr/local/audiobookshelf/audiobookshelf.envServer settings

All of this data stays on your device. It is never uploaded by the package or the publisher.

3. Your rights: access, correction, deletion

  • Access: open the web UI, or read the files listed above directly.
  • Correction: change settings in the web UI or edit audiobookshelf.env at any time.
  • Deletion: uninstall via TOS App Center (apt remove keeps your data; apt purge removes /var/lib/audiobookshelf). No remote copy exists anywhere because nothing was ever uploaded.

4. Third-party network access (user-initiated only)

The application contacts external services only when you enable the related features:

  • Podcast feeds you subscribe to: the feed URL is fetched from your NAS to the podcast's servers on the update schedule you choose.
  • Metadata/book lookups (e.g. Audible, Google Books, OpenLibrary), e-book download sources, OPDS/RSS feeds you publish, and mobile app push notifications (via the Audiobookshelf companion apps) — only when you configure them.
  • Nothing else: no data is sent to Moechz or to any Moechz-operated server.

5. Accounts and children

The application supports multiple local user accounts created by the server admin. It does not knowingly process children's data. The web UI is a local service on your LAN.

6. Changes and contact

Changes to this policy will ship with updated package versions. Contact the packager via the GitHub repository; contact the upstream project at github.com/advplyr/audiobookshelf.

中文版

1. 概述

Audiobookshelf Server 是完全运行在您自己的 NAS 设备（TerraMaster TOS 7）上的自托管有声书/播客服务器。本包（由 Moechz 发布）仅包含 Audiobookshelf 官方上游构建，未添加任何统计、遥测、追踪或广告 SDK，不向发布者收集、传输或共享任何个人数据。

2. 存储在您设备上的数据

数据位置用途
账户名与密码哈希/var/lib/audiobookshelf/config/（SQLite）网页登录
媒体库数据库（书籍、进度、书签、笔记）/var/lib/audiobookshelf/config/absdatabase.sqlite应用核心状态
封面、元数据缓存、已下载播客/var/lib/audiobookshelf/metadata/媒体处理与离线收听
备份/var/lib/audiobookshelf/config/backups/手动/自动备份
服务配置/usr/local/audiobookshelf/audiobookshelf.env服务设置

以上数据全部保存在您的设备上，本包不会将其上传到任何地方。

3. 您的权利：访问、更正、删除

  • 访问：打开网页界面，或直接读取上述文件。
  • 更正：随时在网页设置或编辑 audiobookshelf.env。
  • 删除：通过 TOS 应用中心卸载（apt remove 保留数据；apt purge 删除 /var/lib/audiobookshelf）。因为从未上传，不存在任何远程副本。

4. 第三方网络访问（仅在您启用相关功能时）

  • 您订阅的播客源：按您设置的更新频率从 NAS 直接向播客服务器拉取。
  • 元数据/图书查询（如 Audible、Google Books、OpenLibrary）、电子书下载源、您发布的 OPDS/RSS、移动端推送（经官方伴侣 App）——均仅在您配置后发生。
  • 其他情况零外联：不向 Moechz 或任何发布者运营的服务器发送数据。

5. 账户与未成年人

应用支持管理员创建的多个本地用户账户，不涉及未成年人数据处理。网页界面是局域网内的本地服务。

6. 变更与联系

本政策的变更将随包版本更新发布。打包问题请通过 GitHub 仓库联系；上游项目见 github.com/advplyr/audiobookshelf。
